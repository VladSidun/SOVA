# 1. Чи достатньо даних для початку

Так. Наявної інформації достатньо, щоб почати повноцінну розробку структури, дизайну, адаптиву, SEO-основи, форми заявки, Telegram-інтеграції та двомовності.

Матеріали, які будуть додані пізніше без зміни архітектури:
- реальні фото та відео;
- відгуки;
- кейси студентів;
- профілі викладачів;
- фінальні посилання на окремі месенджери, якщо вони відрізнятимуться від номера телефону.

Секція викладачів у першій версії **не показується**. У коді вона має бути підготовлена як опційний модуль, який можна увімкнути після додавання даних.

Не можна публікувати вигадані фото, відгуки, результати іспитів або фейкові профілі.

# 2. Важливі уточнення перед публічним запуском

Ці пункти **не блокують розробку**, але мають бути узгоджені перед production launch.

## 2.1. «8 років» і «працює з 2019 року»

На момент підготовки цього документа — вересень 2026 року. Формулювання «працюємо з 2019 року» та «8 років роботи» математично можуть суперечити одне одному залежно від точної дати відкриття.

До підтвердження дати:
- у коді зберігати обидва значення окремо;
- у production безпечніше показувати **«Працюємо з 2019 року»**;
- статистику `8 років` увімкнути після підтвердження власником, що вона коректна за їхнім способом підрахунку.

Інші підтверджені показники:
- `100+` студентів навчаються зараз;
- `1000+` студентів пройшли навчання за весь час.

## 2.2. Перенесення занять

Відомо: якщо заняття не відбулося, воно не «згорає», а переноситься.

Перед запуском FAQ треба уточнити правило окремо для:
- індивідуальних занять;
- парних;
- групових.

Для групового формату перенос одного учня може працювати інакше, ніж для індивідуального, тому не формулювати це правило універсально, доки власник не підтвердить.

SOVA — школа англійської мови в центрі Мукачева з офлайн та онлайн навчанням.

Цілями можуть бути:

- НМТ / ЄВІ / інші вступні іспити;
- IELTS / FCE / TOEFL та інші міжнародні іспити;

- робота за кордоном;
- переїзд і комфортне життя за кордоном;
- загальна англійська.

# 4. Tone of Voice

Звертання до користувача — **на «ви»**.

Тон:
- молодіжний;
- професійний;
- доброзичливий;
- сучасний;
- впевнений;
- без канцеляризмів;
- без інфантильності;
- без агресивного sales-copy;
- без надмірної кількості англіцизмів.

Приклад правильно:
> Розкажіть, для чого вам англійська — ми визначимо рівень і підберемо програму під вашу ціль.

Неправильно:
> Купуйте наш найкращий курс вже сьогодні!

# 9. Формати і ціни

Ціни рекомендовано **показувати відкрито**.

Причини:
- ціна конкурентна;
- прозорість підсилює довіру;
- людина одразу розуміє бюджет;
- CTA «безкоштовний урок» знижує ризик першого контакту;
- менше некваліфікованих заявок.

## 9.1. Групове навчання

- 3–5 людей;
- 2–3 рази на тиждень;
- 60–75 хв;
- online / offline;
- **1500 грн / місяць**.

## 9.2. Парне навчання

- 2 учні;
- 2–3 рази на тиждень;
- 60–75 хв;
- online / offline;
- **350 грн / заняття**.

## 9.3. Індивідуальне навчання

- персональна програма;
- частота за узгодженням, типово 2–3 рази на тиждень;
- 60–75 хв;
- online / offline;
- **500 грн / заняття**.

## 9.4. Підготовка до іспитів

Окремої «націнки за іспит» немає.

Студент:
1. називає ціль;
2. проходить визначення рівня;
3. повідомляє дедлайн;
4. отримує індивідуальну програму;
5. обирає формат;
6. платить за стандартною ціною цього формату.

Це варто використати як перевагу:
> **Підготовка до НМТ, ЄВІ та міжнародних іспитів — без окремої «іспитової» націнки.**

Формулювання погодити з власником перед launch.

# 29. Promotions — ідеї на майбутнє

На launch можна **не давати знижок**, бо безкоштовний 45-хвилинний trial + тест + персональний план уже є сильним lead magnet.

Рекомендовані кампанії для тесту пізніше:

### 1. Referral
> Приведіть друга — обидва отримують бонус на наступний місяць.

Величину бонусу визначає власник.

### 2. Family
> Друга людина з однієї сім’ї — спеціальна сімейна ціна.

### 3. Back to School
> Безкоштовне тестування + персональний план до початку навчального року.

Можна без прямої знижки.

### 4. Exam Deadline
> Безкоштовний diagnostic session + roadmap до НМТ / ЄВІ.

Це краще, ніж знижувати ціну.

### 5. Prepay
> Оплата за 3 місяці наперед → невеликий бонус.

Використовувати тільки якщо економіка дозволяє.

Загальна рекомендація:
**спочатку продавати цінність, а не знижку.**

# 36. Domain setup — короткий процес

1. Вибрати 3–5 назв.
2. Перевірити доступність у реєстратора.
3. Зареєструвати домен на власника / бізнес, а не на розробника.
4. Увімкнути 2FA у реєстратора.
5. Підключити DNS.
6. Підключити hosting.
7. Увімкнути HTTPS.
8. Додати домен до Google Search Console.
9. Додати домен у Google Business Profile.
10. Створити корпоративний email пізніше, наприклад `hello@domain`.

# 39. Acceptance criteria

Сайт готовий до public launch, якщо:

- [ ] Hero, CTA, navigation, formats, prices, trial flow, about, method, location, FAQ, form працюють.
- [ ] Звертання всюди на «ви».
- [ ] Групова ціна 1500 грн/міс відображається коректно.
- [ ] Парна ціна 350 грн/заняття.
- [ ] Індивідуальна ціна 500 грн/заняття.
- [ ] Указано 60–75 хв та 2–3 заняття на тиждень там, де доречно.
- [ ] Trial описаний як 45 хв.
- [ ] Form має audience + goals + mode + name + phone + contact method.
- [ ] Telegram admin delivery працює.
- [ ] User fallback WhatsApp/Viber/phone працює.
- [ ] UTM параметри передаються.
- [ ] UA/EN працює.
- [ ] Google Maps CTA працює.
- [ ] Hours Пн–Сб 09:00–20:00.
- [ ] Немає fake teachers/reviews/results.
- [ ] Hidden sections можна активувати config-ом.
- [ ] Mobile не має overflow.
- [ ] SEO metadata / JSON-LD / sitemap / robots готові.
- [ ] Analytics layer не відправляє PII.
- [ ] Lighthouse / accessibility пройдені.
- [ ] Вирішено «8 років vs 2019» перед показом статистики 8 років.
- [ ] Cancellation/reschedule policy узгоджена перед публікацією у FAQ.
- [ ] Реальний SVG logo доданий у repo.
- [ ] Реальні media optimized до launch.
